# Why Doctor's Offices Still Use Clipboards

*   **System:** Legacy workflows, data capture, legal/privacy requirements, system integration challenges, patient accessibility.
*   **Narrator:** Bright, energetic adult female (e.g., AvaNeural).
*   **Palette:** Dark canvas. Stick figures in white. Accent colors: warm amber (the patient/their desire for efficiency), signal blue (the underlying system/rules), coral red (frustration/naive assumptions).
*   **Hero Element:** The clipboard, which represents both a physical object and a symbol of data capture and system interface.
